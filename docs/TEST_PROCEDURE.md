# 実店舗での試験手順（初回）

対象: iPad の Safari（横向き）。開発用データではなく、実店舗の設定を入れた状態で行う。
事前に `docs/UNDECIDED_RULES.md` の項目を確定し、設定画面に入力しておく。

## 0. 準備
1. サーバー（PostgreSQL / Django / Next.js）を起動し、iPad から `http://<サーバーのIP>:3000` を開く。
2. Safari の共有メニュー →「ホーム画面に追加」。ホーム画面のアイコンから起動する（全画面）。
3. 店舗管理者またはスタッフでログインし、店舗を選択する。
4. 「店舗設定・権限」で営業日切替時刻・アラーム段階・税/サービス料・端数処理を確認する。
5. 「時給・バック・料金」でコース（無制限 3,500円 / 1時間 2,500円 / 延長 2,500円）、無制限変更料金、指名・同伴料、バック設定を確認する。
6. 「従業員管理」で当日の出勤者が登録・配属されていることを確認する。
7. バックアップを取る: `scripts\backup-db.ps1`。

## 1. 開店
1. 開店前の卓一覧には「開店（レジ開け）がまだです」と出て、空席をタップしても入店できないことを確認する（出勤は開店前でも押せる）。
2. レジの釣銭を数え、表示の金額（前日の締めで残した翌日の釣銭）と合っていれば「この金額で開店する」。違えば「金額を変える」。
3. 「出勤・お渡し」→ 出勤者の「出勤」を押す。

## 2. 入店 → 注文（POS 操作）
1. 卓一覧で空席の卓をタップ → 人数（＋／−）とコースを選び「入店する」。**自動で卓一覧に戻り**、その卓に経過時間・残り時間・人数・金額が出ることを確認する。
2. 卓をタップ → 商品をタップしてカートに入れる。キャストドリンク・ボトルは「誰の？」を大きなボタンで選ぶ。「注文確定」で **自動で卓一覧に戻る**。
3. 戻った画面下の通知の「取り消す」で、直前の注文がまとめて取り消せることを確認する（約10秒表示）。
4. 注文済みの明細をタップ → 理由ボタン（入力ミス など）で個別に取り消せることを確認する。
5. 「指名・同伴・値引き・席移動など」から、指名・同伴（キャストを選ぶ）、値引き（金額と理由ボタン）、途中合流、席移動を試す。席移動で伝票・時間が失われないこと。
6. カートに商品を入れたまま「← 卓一覧」を押すと、確定するか消すかを聞かれることを確認する。

## 3. 終了前通知 → 延長
1. 終了10分前・5分前に、卓一覧の卓の色と画面上部の通知が出ることを確認する（別画面で注文入力中でも上部に出る）。
2. 画面を再読み込み・iPad をスリープ→復帰し、残り時間が正しく再計算されることを確認する。
3. 「1時間延長」を押すと **確認画面に料金と新しい終了時刻** が出る。「延長する」で終了予定が **元の終了予定時刻 + 1時間** になり、卓一覧に戻る。通知の「取り消す」で延長を戻せる。
4. 別の対象で「無制限へ」を押す。確認画面の変更料金で確定され、時間のお知らせ対象から外れる。
5. 通知を閉じても、時間超過の卓は卓一覧で赤表示のまま残ることを確認する。
6. ロック中・他アプリ利用中は通知されない（初版の保証外）ことをスタッフに周知する。

## 4. 会計
1. 卓をタップ →「会計する」。大きく出るご請求額と内訳を確認する。
2. 現金: 「お預かり」に受け取った金額を入れる（「ちょうど」や ¥5,000・¥10,000 などのボタンでも可）→ **お釣りが大きく表示** される →「会計する」→ 確認画面で「確定する」→ 完了画面にお釣りが大きく出る。
3. カード:
   - 決済端末を連携していない店: 既存の決済端末に金額を手入力して決済 → 端末で成功を確認してから「端末で決済できた → 会計する」。
   - 決済端末を連携した店（店舗設定 → カード端末）:「決済端末に送る」→ 端末に金額が出る → お客様がカードを読み取る → 画面が自動で「お会計完了」になる。
     拒否されたとき・「送信を取り消す」を押したときは会計されず、もう一度送るか別の方法で払えることを確認する。
     読み取り待ちの間に別の iPad・PC で同じ伝票の会計画面を開くと、同じ読み取り待ちの画面が出ることを確認する。
   - 模擬端末（テスト用）では、画面の「（テスト）承認」「（テスト）拒否」で結果を選ぶ（実際の決済はしない）。
   - 端末の調子が悪いときは「端末に金額を手で入れて決済した場合はこちら」で従来の手入力に切り替えられる。
4. 現金＋カード: 先にカードの金額を入れる → 現金で払う分が自動で出る → お預かりを入れてお釣りを確認。
5. 分割会計:「一部だけ会計する」で明細を選んで会計し、残りを続けて会計できることを確認する。
6. 確定ボタンを連打しても会計が1件だけ作られることを確認する（会計履歴で件数を確認）。
7. 完了画面の「手書き領収書の金額」で税込合計・税抜金額・税額・現金/カードの支払額を見て手書きする。お預かり・お釣りは領収額と区別されている。

## 5. バック集計
1. 「勤怠・支払集計」→「バック集計」で、注文時に選んだ従業員に設定どおりのバックが確定していることを確認する。
2. 会計取消（売上・会計履歴 → 詳細 → 会計を取消）を1件試し、バックが打ち消され、返金記録ができることを確認する。カードの場合は端末側で別途取消が必要。

## 5-2. 退勤 → 日払いのお渡し
1. 上部の「出勤・お渡し」→ 出勤するときに各自の「出勤」を押す（休憩は「休憩開始／終了」）。
2. 帰るときに「退勤」を押すと、「お疲れさまでした」と **本日のお渡し額（時給×勤務時間＋その日の確定バック）** が大きく出る。
3. レジの現金から手渡ししたら「渡した」。レジの現金出金（日払い）と支払記録が同時に1件だけ作られる。もう一度押せないこと、通知の「取り消す」で戻せることを確認する。
4. 一部だけ渡す場合は「金額を変えて渡す」。残りは未渡しとして残り、あとで渡せる。
5. 時給が未設定の人は計算できず「時給未設定」と出る（オーナーが従業員管理で設定）。

## 6. レジ締め（順番に進むだけ）
1. 未会計の卓が残っていると「レジ締めを始める」が押せない（赤い表示とその卓へのボタンが出る）。会計するか伝票を取り消す。
2. 「レジ締めを始める」→ **お渡しがまだの人** がいれば最初に出る。手渡ししたら「渡した」。渡さずに「次へ」でも締められる（あとで渡せる）。
3. **レジの現金はいくら？** に数えた合計を入れる（お札・小銭の枚数で数えることもできる）→「次へ」。
4. ぴったりなら「✓ ぴったりです」。ずれていたら「数え直す／お釣りの渡し間違い／原因不明／その他」から選ぶ。翌日の釣銭は今日と同じ額が自動で入っている（変える場合だけ「変える」）。
5. 「レジ締めを確定」→「お疲れさまでした」と **銀行に入金する現金** と **本日の手残り（目安）** が大きく出る。
6. 翌日、銀行に入金したら「締め履歴」から「銀行入金」を記録する。翌日の開店時に釣銭準備金が引き継がれていることを確認する。
7. 締めた後の入出金の取消はできない（締めの数字と合わなくなるため）。必要なら「この営業日を再開する」（理由と操作者が記録される）→ 直して → もう一度締める。
8. 給与の「締め」は不要（日払いでその日に精算済み）。「期間の集計（確認用）」は、期間の支払額を確認したいときだけ使う。

## 7. 確認事項の記録
- 画面の文言・ボタンの大きさ・暗い店内での見やすさ
- Safari 固有の挙動（ホーム画面追加後の再読み込み、スリープ復帰）
- 通信が切れた時のエラー表示と、再接続後の状態照合（画面を更新して確定状態を確認）
