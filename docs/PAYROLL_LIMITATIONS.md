# 支払集計の範囲と、正式な給与計算に必要な未対応事項

本アプリの「勤怠・支払集計」は **勤務時間 × 時給 ＋ 確定バック − 実際に支払った額** を集計する機能であり、
法定控除まで完成した給与計算ではありません。画面にもその旨を表示しています。

## 現在計算しているもの
- 勤務時間: 出勤〜退勤から休憩を除いた分数（分未満切り捨て）。日付をまたぐ勤務は営業日に紐付く。
- 時給分: 勤務日（営業日）時点で有効な時給設定 × 勤務分 ÷ 60（円未満切り捨て、勤務ごと）。
- バック: 確定済み（confirmed）のバックエントリの合計（取消は打消しエントリで相殺）。
- 実支払額: 日払い・前払い・締め支払い・その他（取消分を除く）。レジ現金からの日払いは現金出金と1対1で紐付く。
- 残額 = 支給対象額 − 実支払額。締め期間を締めると明細をスナップショットとして固定する。

## 未対応（雇用区分・ルールが未確定のため根拠なく決めていない）
| 項目 | 必要な確認事項 |
|---|---|
| 所得税（源泉徴収） | **ホステス報酬は対応済み**（経理 → キャスト契約で税務区分を確定した人だけ。`docs/ACCOUNTING_DESIGN.md`）。給与所得（甲欄/乙欄/丙欄、扶養控除等申告書、年末調整）は未対応で、給与計算ソフトの結果を入力する |
| 住民税 | 特別徴収の有無 |
| 社会保険・雇用保険 | 加入要件（勤務時間・日数・契約期間）、料率、折半 |
| 割増賃金 | 深夜（22時〜5時）25%、時間外、法定休日の扱い。労働時間管理の方法 |
| 最低賃金・固定給との併用 | 都道府県別の最低賃金、日給・月給制の有無 |
| 歩合・バックの税務上の扱い | 給与に含めるか、報酬として扱うか |
| 交通費・立替精算 | 非課税限度額、精算フロー |
| 支給サイクル | 締め日・支払日、日払い上限、前払いの扱い |
| 端数処理 | 勤務時間の丸め（法令上は1分単位が原則）、金額の端数 |
| 給与明細・帳票 | 法定の明細記載事項、保管期間 |

これらが確定するまでは、本アプリの集計を「支払集計（概算）」として扱い、正式な給与計算は税理士・社労士等と確認した方法で行ってください。
