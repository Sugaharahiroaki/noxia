# 営業開始前にオーナーが確定すべき設定（未確定の業務ルール）

開発用データ（`manage.py seed_dev`）に入っている値はすべて **仮設定** です。実際の営業データを登録する前に、
店舗ごとに「店舗設定・権限」「時給・バック・料金」画面で確定してください。未設定のままだと操作がエラーになる項目もあります（0円扱いにはしません）。

| 項目 | 設定場所 | 仮設定（開発用） | 判明している情報 / 備考 |
|---|---|---|---|
| コース料金の単位（1人 / 1組） | 店舗設定 → 料金の単位・税 | 1人単位 | 未確定 |
| 価格の税込・税別 | 同上 | 税込（内税）10% | 未確定 |
| サービス料の有無・料率・計算対象・計算順序・値引き後に計算するか | 店舗設定 → サービス料 | 本店: なし / 二号店: 10% | 未確定 |
| 端数処理（税・サービス料・合計の丸め） | 店舗設定 → 端数処理 | すべて切り捨て、合計は1円単位 | 未確定 |
| 時間制 → 無制限への変更料金 | 料金設定 → 無制限変更 | 固定額 1,000円（**例**。差額1,000円をハードコードしていない） | 未確定。未設定なら変更操作はエラー |
| 延長後に無制限へ変更するときの料金 | 同上 | 通常の変更料金と同じ | 未確定 |
| 指名料・同伴料（お客様への請求額） | 料金設定 → 指名・同伴 | 1,000円 / 2,000円 | 未確定。未設定なら登録不可 |
| コース料金・延長料金 | 料金設定 → コース | 無制限 3,500円、1時間 2,500円、延長 2,500円/1時間 | 判明済み（スクリプトに反映） |
| 商品価格・税率 | 商品・在庫 → 商品マスタ | ダミー価格 | 未確定（シャンパン・テキーラは別料金） |
| 終了アラームの段階（10分前 / 5分前 / 両方） | 店舗設定 → アラーム | 両方 | 未確定 |
| 営業日の切替時刻 | 店舗設定 → 営業日 | 06:00 | 未確定。深夜0時をまたいでも同じ営業日として集計 |
| 既定の釣銭準備金 | 店舗設定 | 50,000円 | 未確定 |
| ツケ・未収の利用可否 | 店舗設定 → 会計 | 本店: 可 / 二号店: 不可 | 未確定 |
| バックのルール（固定額/割合、対象、税込/税抜基準、値引き・サービス料の扱い、端数、確定時点） | 料金設定 → バック設定 | キャストドリンク 50%、ボトル 10%、指名 500円、同伴 1,000円、個人別の例 | 未確定 |
| 時給（基本・個人別・適用開始日） | 従業員管理 → 時給 | 1,300〜2,000円 | 未確定 |
| 締め日・支払日 | 勤怠・支払集計 → 締め期間 | なし | 未確定 |
| 売上の従業員への帰属ルール | （実装上は伝票の「担当」に帰属。指名・同伴件数は対象従業員に集計） | — | 未確定。分析画面の定義を確認 |
| 顧客情報の会社内共有 | 会社管理 → 会社設定 + 顧客ごとの共有フラグ | A社: 不可 / B社: 可 | 未確定 |
| 発注の確定フロー・仕入先への連絡手段 | 仕入先・発注 | 手動連絡（自動送信なし） | 未確定 |

## 設計上の前提（変更する場合はコード変更が必要）
- 延長は「元の終了予定時刻」から延長分を加算する（操作時刻からではない）。
- 無制限へ変更した対象は時間制アラームの対象から外れる。
- 価格・税率・バック条件は取引時点の値を明細・バックエントリに保存する。マスタを変更しても過去の金額は変わらない。
- 会計済み明細は直接書き換えない。訂正は「会計取消」（返金記録＋明細を伝票に戻す）または「一部返金」で行う。
- 分割会計では税額・サービス料を「その会計分」だけで計算する（伝票全体の税額を按分表示しない）。
- 未収の回収は売上として再計上しない（現金出納には「未収回収」として入る）。
- レジ現金からの日払いは「現金出金」と「従業員への支払記録」を同時に1件作る（二重控除しない）。
