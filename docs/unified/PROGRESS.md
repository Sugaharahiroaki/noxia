| 時間報酬（労働時間 × 時給） | 既存の `shift_wage`（分単位・円未満切り捨て。休憩を除く） |
| 呼び／場内／同伴の本数バック、ドリンク・ボトル・フードバック | 既存の `BackEntry`（確定分）を種別・商品カテゴリで分けて集計 |
| 呼び小計バック・同伴小計バック | **足した**（A8）。会計の確定時に、指名（本指名・場内）／同伴の対象の人へ、会計の小計 × 率のバックを作る。取消・返金・会計の削除は既存の打消し／削除に乗る |
| ボーナス | 既存の手入力のバック調整（正の額）。項目名は「バック調整」で、手当として記録する仕組みは無い |
| マイナス（遅刻・欠勤など） | 既存のバック調整（負の額）。遅刻・欠勤を分けた項目は無い |
| 日払い | 既存の `EmployeePayment`（渡した額） |
| 厚生費 | 既存の控除（`payout_deductions`・契約の控除）で実際に差し引いた額（`deduction_amount`）。厚生費だけを分けた列は無い（Q12） |
| 源泉所得税 | 既存（日払いのお渡しのときに計算・記録した額）。オンの店舗だけ表示 |
| 月給・月次調整 | NOXIA に無い（時給とバックだけ）。作っていない |

### 決めた扱い
- 小計バックの基準額は会計の小計（ルールが「値引きを反映」なら値引き後）。対象が複数人なら均等割り（円未満切り捨て、余りは従業員 ID の小さい人）。固定額のルールは 1 会計あたりの額。確定の時点はルールの設定に従う（入金完了時確定でツケがあれば未確定のまま）。
- 分割会計では、指名・同伴の明細が入った会計の小計だけが基準になる。
- 「オーダー小計」は、その人がバック対象になっている商品の明細の金額の合計（折半の明細は各人に全額を計上）。
- キャスト／スタッフの区分は、店舗の配属の役割（cast がキャスト、それ以外がスタッフ）。
- 用語は「報酬」に統一（画面に「給与」は出していない。「給率」は参考設計の指標名なのでそのまま）。

### 仮の扱い・決まっていないこと
- 小計バックが複数人のときの分け方（均等割り。Q4 と同じ論点）。集計の設定「全員に全額」は集計の表示だけに効き、バックの計算には使っていない。
- 小計バック（kind = `yobi_subtotal`・`douhan_subtotal`）は、経理の報酬項目では「その他バック」に入る（経理側は変更していない。Q19 と同じ扱い）。
- 厚生費の計算（対象項目と率）は Q12 のまま（既存の控除の範囲）。
- 給率の分子・分母の切替、ポイント、体入・派遣のマークは作っていない。
- 報酬支払明細の PDF は M6。
