## 1. 全体像

元アプリは **2層構成**。

| 層 | 役割 | 今回の扱い |
|---|---|---|
| タブレット用（伝票入力） | 伝票作成、セット・指名・注文入力、会計、レシート印刷 | 元はApp Storeアプリ。クローンでは**同じURLにタブレット用ログインで入るとタブレット表示になる**方式にする。**仕様は別途受領予定のため今回は対象外** |
| 管理用（PC表示） | 集計・日報（勤怠）登録・報酬計算・現金管理・各種設定 | **今回の実装範囲**。本設計書はこの管理用の仕様 |

**今回のスコープ（管理用のみ）での注意**
- 伝票系のモデルとAPI（サービス層）は管理用フェーズで先に作る。タブレット画面は後から同じモデルに書き込む。
- ログインは「管理用」「タブレット用」の2種類のロールを最初から用意し、ロールで表示（PC用レイアウト／タブレット用レイアウト）を切り替えられる構造にしておく。タブレット側は今はプレースホルダーページのみ。
- タブレット画面ができるまでは、seedデータと管理用の「伝票修正」画面で伝票を用意して集計を検証する。

**業務形態の前提**
- キャストは**完全に業務委託**。**源泉徴収は行わない**（機能自体を作らない）。帳票名は「報酬支払明細書」とし、「給与」ではなく「報酬」の用語で統一する。

データの流れ:

```
伝票(セット/指名/注文/会計) ─┐
日報(キャスト勤怠/スタッフ勤怠/入出金) ─┼→ 日次収支 → 月次収支 → まとめ(ダッシュボード)
店舗設定(バック率/時給/端数処理) ─┘        └→ キャスト報酬明細 / スタッフ報酬明細 / レジ精算
```

## 6. 計算ロジック

### 6.1 営業日（✅確認済み）

- 店舗設定「開業時間」を日付の区切りにする。深夜01:10入店の伝票は前日の営業日に計上される。
- `business_date = (entered_at − 開業時間).date()`

### 6.2 伝票（✅確認済み／一部🔶）

```
小計       = Σセット料金 + Σ指名料 + Σ注文
サービス＋税 = 小計 × 率
              現金払い(料金A) = 15%   例: 26,000 → 3,900 → 合計29,900
              カード払い(料金B) = 20%  例: 22,000 → 4,400 → 合計26,400
合計(本計)  = 小計 + サービス＋税 − 値引き + 値増し  → 端数処理
内消費税    = 合計 × 10/110（29,900 → 2,718）
お釣り      = 預かり合計 − 合計
合計        = 現金 + カード + 売掛
```

- ✅ **サービス料率は支払方法で変わる: 現金15%、カード20%**。元アプリの名称辞書でも「料金A=現金払い」「料金B=カード払い」となっており、伝票に料金区分を持たせて率を切り替える。率は ShopSetting（`service_rate_cash=15`, `service_rate_card=20`）で変更可能にする。
- この差があるため、**本計は支払方法で変わるが小計は変わらない**。キャストの呼び小計・バックは小計ベースなので支払方法の影響を受けない。本計ベースの指標（女子本計、総売上、客単価）は影響を受ける。
- 🔶 現金とカードの併用、売掛の場合にどちらの率を使うかは未確認（11章）。
- 🔶 端数処理: 22,500×1.15=25,875 が 25,900 になっており、100円単位の切り上げと推定。単位・丸め方は設定化する。
- 用語: **本計** = 税サ込みの合計、**小計** = 税サ抜きの金額。

### 6.3 キャスト売上（✅確認済み）

- 指名が付いた伝票の小計は、指名キャストの「呼び小計」に計上される（他キャストが受けたドリンクも含め伝票小計の全額。実例: 小計26,000の伝票 → 指名キャストに26,000）。
- `呼び本計` = 指名が付いた伝票の合計(本計)の総和、`呼び小計` = 同じく小計の総和。同伴も同じ構造。
- 指名回数: 設定「呼びされたセット数分カウント」のとき、伝票内のセット数だけ加算（2セット指名=2.0回、組数は1）。「1伝票1本のみ」も選べる。
- ハーフセットのカウント: 1固定 / 0.5固定 / 初回1・2回目以降0.5。
- 複数キャストに指名が分かれる場合の配分、キャスト売上の計算対象（本計から／選択した項目から、値引き・値増しを含めるか、カード手数料の割り戻し/カット）は店舗設定で切替（8章）。

### 6.4 キャスト報酬（✅確認済み）

```
労働時間(10進)   = (終了 − 開始 + 調整分) / 60     例 22:00〜02:15 → 4.25
時間報酬         = 労働時間 × 時給                  例 4.25 × 1,400 = 5,950
呼び小計バック    = 呼び小計 × 呼び売上バック率       例 81,500 × 5% = 4,075
同伴小計バック    = 同伴小計 × 同伴売上バック率       例 34,100 × 5% = 1,705
呼び/同伴の本数バック = 回数 × 設定金額
ドリンク/ボトル/フードバック = Σ(メニュー別バック額 × 個数)
                   例 1,000円ドリンク×20(各300) + 1,500円ショット×1(500) = 6,500
バック計         = 上記バックの合計
総支給額         = 時間報酬 + バック計 + ボーナス      例 5,950 + 4,075 + 6,500 = 16,525
厚生費           = 厚生費対象項目の合計 × 厚生費率
残り支給額       = 総支給額 − 厚生費 − マイナス(遅刻/欠勤等) − 日払い
                   例 11,550 − 10,000 = 1,550
平均時給         = 勤怠給 ÷ 勤務時間（設定で「総支給額÷勤務時間」も可。2部の時間は除く）
給率(キャスト)    = 総支給額 ÷ 呼び小計 × 100          例 64,260 / 179,100 = 35.9
```

- 給率の分子（総支給額/勤怠給）・分母は設定で変更可。端数計算も設定。
- 月給・月次調整額は**日別には出さず月合計にだけ**反映する。
- **源泉徴収はしない**（キャストは完全に業務委託）。控除は厚生費・マイナス・日払いのみで、総支給額から源泉税を引く処理は実装しない。
- 締め日: 設定「女子報酬締め日」（99=月末）。月末以外なら集計期間がずれる。
- ポイント: 小計/呼び/同伴/場内/ドリンク/ボトル/フードごとに付与ルールを設定（1伝票の売上で付与 or キャストの日合計で付与、会計毎1回 or セット毎）。

### 6.5 スタッフ給与

```
支給額   = 基本給(時給×労働時間) + 基本給(日給) + 基本給(月給) + 賞与
残り支給額 = 支給額 − 厚生費 − 罰金(遅刻/欠勤) − 日払い
```

### 6.6 日次・月次収支（✅確認済み）

```
総売上      = Σ伝票合計 = 現金 + カード + 売掛
女子売上    = 呼び本計（指名付き伝票の本計）
人件費-女子  = Σキャスト総支給額(当日)      人件費-男子 = Σスタッフ支給額(当日)
経費計      = 人件費 + 出金(粗利対象)
粗利(日別)   = 売上計 + 入金 − 人件費 − 経費
              ※入金(粗利×)、出金(粗利×)、出金(現金以外/粗利×)は除く
              例 97,800 − 28,075 = 69,725
給率(店舗)   = キャスト給与計 ÷ 売上計          例 28,075 / 97,800 = 28.71%
客単価      = 売上 ÷ 来店人数（四捨五入）       例 488,300 / 41 = 11,910
組単価      = 売上 ÷ 来店組数                  例 488,300 / 20 = 24,415
平均(1営業日) = 累計 ÷ 伝票がある日数
```

- まとめ画面の「粗利(累計)」は日々の粗利の累積。月給・月次調整は当月なら当日（または前日）、過去月なら月末日に反映。
- まとめ画面の「タグ対象額」= タグが付いた伝票の販売額合計、「女子本計」= 呼び本計の月合計。

### 6.7 現金管理（✅確認済み）

```
レジ内現金(理論値) = 本日釣銭 + 現金売上 + 入金合計 − 出金合計（日払報酬 女子/男子を含む、現金対象のみ）
現金過不足        = レジ内現金(実数=金種×枚数の合計) − 理論値
預金金額          = レジ内現金 − 翌日釣銭準備金
翌日の本日釣銭     = 前日の翌日釣銭準備金
```

- 実例: 現金売上97,800 − 日払10,000 = 87,800 → 預金金額87,800。
- 自動精算: 金種を自動入力して過不足0で締める。設定で「前日が未精算なら自動でレジ精算」。
- 当月累計（過不足・預金）を日次画面に表示。

### 6.8 タグ集計・商品集計

- 1伝票に複数タグが付く場合、タグごとにその伝票を重複計上する（合計はタグ行の単純合計と一致しないことがある）。
- 列: 件数、客数、伝票小計、現金、カード、売掛、販売額。「通常集計／色別集計」切替。
- 商品集計: 日付×メニューの個数、キャスト×メニューの個数。折半注文は 単価÷人数（切り捨て）を各キャストに計上（10,000円を3人→3,333円×3）。

### 6.9 お客様分析

- 顧客ランク: 直近3ヶ月の来店回数で S(20回以上)/A(10)/B(5)/C(1)/D(0)。しきい値は設定。
- 項目: 状態、キープ、来店回数、最終/初回来店日、来店時間平均、累計滞在時間、単価、会計、金種、タイプ、キャストへの注文、お客様(スタッフ)注文、本指名、場内指名、同伴、テーブル。
- キープ有効期限の初期値 = 開始日 + 設定値（既定3ヶ月）。

ナイト業態（ガールズバー/キャバクラ等）向けの店舗管理Webアプリ。
