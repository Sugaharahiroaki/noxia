# Claude Code に渡すプロンプト集

VS Code の Claude Code で、NOXIA のリポジトリ（このフォルダ）を開いて使う。

## 使い方
1. 上から順に、**1 ブロックずつ** 貼り付ける。1 ブロック = 1 フェーズ = 1 コミット。
2. フェーズが変わるたびに `/clear` で会話を切る（`CLAUDE.md` と計画書は毎回自動で読まれる）。
3. 各フェーズの報告を読み、「決まっていないこと」が増えていたら `docs/unified/UNIFIED_PLAN.md` の 6 章に足してから次へ進む。
4. P0 は必ず最初に 1 回だけ流す。S1 はオーナーの回答が出るまで流さない。

順番: **P0 → T1 → T2 → T3 → T4 → T5 → T6 → T7 → M1 → M2 → M3 → M4 → M5 → M6**（S1 は回答が出たとき）

どのプロンプトにも共通する決まり（金額計算の場所、テナント検証、冪等、テストの通し方、報告の書き方）は `CLAUDE.md` に書いてあるので、プロンプトでは繰り返していない。
