# 法令・税務上の要確認事項

NOXIA の源泉徴収・経理機能で、一次資料で確認できたこと（実装の根拠）と、確認できなかったため推測で実装していないこと（要確認）の一覧です。
確認日: 2026-11-02。税理士等の確認を経てから本番運用してください。

## A. 一次資料で確認し、実装に反映したこと

| 内容 | 根拠（一次資料） | 実装 |
|---|---|---|
| ホステス等の報酬の税額 =（報酬 − 5,000円×計算期間の日数）× 10.21%、1円未満切り捨て。同じ期間に給与等があれば控除額から差し引く | 国税庁 タックスアンサー No.2807（令和8年4月1日現在法令等）、所得税法204条1項6号・205条2号、施行令322条 | `withholding.py`、ルール表 |
| 計算期間の日数は営業日数・出勤日数ではなく、計算の基礎となった期間の全日数 | 同 No.2807（最高裁平成22年3月2日判決も同旨） | 暦日数で計算 |
| 報奨金・衣装代・深夜帰宅のタクシー代も源泉徴収の対象 | 同 No.2807 | 報酬項目の既定は「すべて対象」 |
| 国税庁の計算例（3/1〜31・75万円 → 60,749円） | 同 No.2807 | テストで一致を確認 |
| 令和9年1月から防衛特別所得税（所得税額の1%）、復興特別所得税は1.1%に（令和29年まで）。合計の付加税率は2.1%のまま | 国税庁「令和9年分 源泉徴収税額表」 | 2027-01-01 から別ルール（10.21%） |
| 納期限は支払った月の翌月10日。ホステス報酬は納期の特例の対象外 | No.2807、源泉徴収税額表 | 毎月の期限、特例は給与のみ |
| 納期の特例（給与等）: 1〜6月分は7月10日、7〜12月分は翌年1月20日 | 源泉徴収税額表 | 給与のみ半年 |
| 10日・20日が土日祝日などの休日に当たる場合は休日明け | 源泉徴収税額表（国税通則法10条2項） | 祝日計算＋12/29〜1/3 |
| 報酬・料金等の徴収高計算書: ホステス等は区分コード08、人員は実人員、支払額は総額、施行令322条の控除額は摘要「支払額からの控除額」に合計 | 国税庁「納付書の記載のしかた（報酬・料金等の所得税徴収高計算書）」 | 転記用データ・PDF |
| 「年度」は納付する日の属する会計年度、「納期等の区分」は元号・年・月（例 50901） | 源泉徴収税額表「納付書の記載のしかた」 | 転記用データ |
| 給与の徴収高計算書: 日雇労務者の賃金は延べ人員。納付税額がなくても計算書の提出が必要 | 同上（給与所得・退職所得等） | 転記用データ・注意書き |
| freee: アクセストークン6時間・リフレッシュトークン90日・1回限り。振替伝票作成の応答から txn_number 削除（2026-07-01〜） | freee Developers Community | `freee.py` |
| freee の「他社会計ソフト仕訳のインポート」で借方・貸方の列の CSV を取り込める（列は取込時に割当て） | freee ヘルプセンター | 仕訳CSV |

## B. 要確認（推測で実装していない・または暫定の扱い）

| # | 事項 | 現在の扱い | 確認先 |
|---|---|---|---|
| 1 | **月単位の契約で日々前払い（内払い）する場合の控除額の当て方**（前払いのたびにその月の控除額の未使用分を使う方式でよいか、月末の精算時にまとめて計算すべきか） | 前払いのたびに月の控除額の未使用分を使い、超えた日から源泉徴収（累計で月の計算と一致する方式）。一次資料で明示された取扱いは見つからず | 税理士・所轄税務署 |
| 2 | 同じ計算期間に追加で支払う場合（バックの追加・訂正）の控除額 | すでに使った日の控除は使わない（控除の重複なし）。残りがあればそれを使う | 税理士 |
| 3 | 同じ事業者の複数店舗で同じキャストに別々に支払う場合の控除額 | 事業者単位で共有（重複しない） | 税理士 |
| 4 | 支払時に税務区分が未確認で源泉徴収しなかった支払いを、後でホステス報酬と確定した場合の扱い（本人からの回収か、支払者負担としてグロスアップか） | 支払った額を報酬として税額を計算し、「支払時に未徴収」として支払月に計上（グロスアップはしない） | 税理士 |
| 5 | 源泉税率の切替を「支払日」で判断すること（2027年の防衛特別所得税） | 支払日で選択（合計税率は同じなので税額は変わらない。内訳・根拠の版が変わる） | 税理士 |
| 6 | 消費税の扱い（報酬と消費税額が明確に区分されている請求書がある場合に税抜で源泉徴収できるか） | 区分しない（報酬総額を対象）。キャストが課税事業者で請求書がある場合の対応は未実装 | 税理士 |
| 7 | インボイス未登録のキャストへの報酬の扱い（取引条件の見直し） | 一律の「インボイス税」の控除は登録不可。個別の合意は契約書で | 税理士・弁護士（独占禁止法・フリーランス新法） |
| 8 | 厚生費などの控除の可否・税務上の扱い（雑収入か報酬の減額か） | 源泉税の対象額を減らさず、別項目。仕訳は雑収入（科目は変更可） | 税理士・社労士 |
| 9 | **雇用か業務委託かの判定**（チェック項目は判断の補助にすぎない） | 経営者が確定（理由必須）。チェックが多いと警告 | 税理士・社労士・弁護士 |
| 10 | 給与所得の源泉徴収（甲・乙・丙欄、扶養控除等申告書、社会保険料、年末調整、日払い給与の丙欄の2か月要件） | **計算しない**。給与計算ソフトの結果を入力 | 社労士・税理士・給与計算ソフト |
| 11 | 深夜割増・最低賃金・社会保険・雇用保険（雇用の場合） | 未対応（既存の `PAYROLL_LIMITATIONS.md` のとおり） | 社労士 |
| 12 | 報酬・料金の**支払調書**（ホステス報酬は年50万円超で税務署へ提出）と個人番号の取扱い | 未実装。NOXIA は個人番号を保存しない（別の安全な仕組みが必要） | 税理士 |
| 13 | 納付税額が0円のホステス報酬の徴収高計算書の提出要否 | 給与は提出が必要と明記。報酬・料金等の0円の月の扱いは画面で案内していない | 所轄税務署 |
| 14 | 延滞税・不納付加算税の計算 | 計算しない（期限超過の表示のみ） | 税務署・税理士 |
| 15 | **e-Tax への取込形式**（所得税徴収高計算書データの正式な仕様・CSV 取込の可否） | 確認できていないため、転記用（独自形式）とだけ表示。e-Tax へのデータ連携・API は実装しない | 国税庁（e-Tax 仕様書）。将来、公式仕様と法的要件が確認できた場合に検討 |
| 16 | 記帳代行サービスの業務範囲（税理士法52条: 税務代理・税務書類の作成・税務相談は税理士の独占業務） | 記帳代行担当者は記帳・照合・出力まで。税務区分の確定・月次の確認・申告書作成・e-Tax 送信は不可 | 弁護士・税理士（サービス約款） |
| 17 | 電子帳簿保存法の要件（真実性: 訂正削除の履歴・事務処理規程、可視性: 検索要件・見読性）を NOXIA の仕組みで満たせるか | 証憑の論理削除・ハッシュ・登録者・検索（日付・金額・取引先）を実装。事務処理規程は未作成 | 税理士 |
| 18 | 証憑・帳簿の保存期間（法人7年・欠損金の繰越は10年、個人7年・書類により5年） | 保存期限の目安を表示（法人10年・個人7年で計算） | 税理士 |
| 19 | freee の勘定科目・税区分の選び方（キャスト報酬を「支払報酬料」「外注費」「給料手当」のどれにするか、売上の税区分） | 既定名を用意し、事業者ごとに対応付け | 税理士 |
| 20 | freee API の利用条件（アプリ登録・公開範囲・利用規約・レート制限）と、NOXIA 運営者が複数の顧客事業所に接続する場合の契約形態 | 本番接続はサーバー設定で停止中。模擬接続のみ | freee（アプリ審査）・弁護士 |
| 21 | 同じ営業日に現金の会計を取り消すとレジ締めの理論現金が二重に減る（既存の不具合） | **2026-11-11 修正済み**（受け取った現金 − 返金 で計算。`cash.services.day_summary`）。修正後の締めの数字は実店舗で一度確認する | 開発（修正済み） |
