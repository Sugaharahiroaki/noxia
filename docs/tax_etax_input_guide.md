# 国税庁かんたん入力ガイド 設計（最優先機能）

状態: **Phase 0 の設計**。2026-11-11 時点の公式資料に基づく。Phase 5 で実装。
目的: NOXIA 利用者が国税庁「確定申告書等作成コーナー」の画面を見ながら、NOXIA が集計した数字を順番に入力できるようにする。**NOXIA は申告書を送信しない**。

## 2. 作成コーナーの入力の流れ（令和7年分の公式ガイドで確認。令和8年分は公開後に再確認）

```
トップ → 作成開始 → 事前確認（提出方法）→ 作成する申告書等の選択
  「決算書・収支内訳書（＋所得税）」を選ぶ
  → 【決算書等の作成】 青色申告決算書（一般用）／収支内訳書（一般用）の選択
       2.1 売上（収入）金額・仕入金額の入力（月別）
       2.2 給料賃金の入力  2.3 専従者給与の入力
       （経費の各科目の入力）
       7. 青色申告特別控除の入力  8. 貸借対照表の入力（10万円控除では不要）
       9. 所得金額の確認
  → 【所得税の申告書】 申告する所得の選択等 → 収入・所得の入力 → 控除の入力（1/2・2/2）
  → 計算結果の確認 → 還付・納付方法等の入力 → 財産債務調書・住民税等 → 基本情報の入力
  → マイナンバーの入力 → 送信前の申告内容確認 → 送信準備 → 送信（または印刷）
```

出典: 決算書作成（青色申告）編 https://www.keisan.nta.go.jp/r7/tebiki/kessan/r7kessan01.pdf 、決算書→申告書の引継ぎ https://www.keisan.nta.go.jp/r7/tebiki/syotoku/r7syotoku02.pdf 、所得税編 https://www.keisan.nta.go.jp/r7/tebiki/syotoku/r7syotoku01.pdf

**年度ごとに画面が変わるため、ガイドの項目と順番は `TaxYearConfiguration.guide`（年度別の設定データ）で管理し、公式画面で確認できていない項目名・順序は `official_label=null`・`verified=false` のまま「要確認」と表示する**（推測で固定しない）。

## 3. ガイドの構成（仕様 §12 に対応）

各項目: `key`（計算値のキー）、`label`（NOXIA の表示名）、`official_label`（作成コーナーの項目名。未確認なら null）、`section`、`order`、`value`（computed から）、`help`（短い説明）、`verified`、`copyable`。

### 第3部 申告確認

| order | 内容 |
|---|---|
| 3-1 | 入力金額の照合: 作成コーナーの「計算結果の確認」画面の数字を NOXIA の計算値と見比べるチェック（事業所得・所得控除合計・課税所得・税額・納付額）。違えば「どの項目から見直すか」の案内 |
| 3-2 | 未入力項目: チェックが付いていない項目の一覧 |
| 3-3 | 提出前確認: 青色承認、インボイス登録・消費税、未対応項目（unsupported）の有無、締めていない営業日・未承認領収書・未照合明細の残り |
| 3-4 | 申告データ保存の案内: 「作成コーナーの『入力データを保存する』で `.data` を保存し、翌年の作成に使う」 |
| 3-5 | e-Tax 送信・受付確認の案内: マイナンバーカード方式／ID・パスワード方式、送信後にメッセージボックスで受付結果（受信通知）を確認、印刷提出の場合は添付書類と提出先 |
| 3-6 | NOXIA 側の記録: 「この版で申告した」を押す → `TaxReturn.status=filed_by_user`、版を `is_final` に |

## 4. 白色・青色の違い

| 項目 | 白色（収支内訳書） | 青色 10 万円（決算書） |
|---|---|---|
| 作成コーナーで選ぶ書類 | 収支内訳書（一般用） | 青色申告決算書（一般用） |
| 月別売上・仕入 | 不要（年計） | 月別の入力あり |
| 専従者 | 事業専従者控除（⑳） | 専従者給与（届出） |
| 特別控除 | なし | 10 万円（7 で選択） |
| 貸借対照表 | なし | 不要（10 万円控除） |
| 損失の繰越 | なし（未対応） | 純損失の繰越（入力） |

## 5. 画面と機能

| 機能 | 実装 |
|---|---|
| 年度・申告区分の選択 | `GET /api/tax/years`、`TaxReturn.filing_type` |
| 国税庁の入力順序に沿った表示 | `guide[]` を section/order で表示。公式確認済みは項目名を太字、未確認は「要確認」バッジと「公式画面の項目名を確認してください」 |
| 金額の自動集計 | `computed` から。更新日時と版番号を表示。計算が古い（仕訳が変わった）場合は「再計算」を促す |
| ワンタップコピー | `CopyButton`（`navigator.clipboard.writeText`、カンマなしの整数文字列）。失敗時は選択状態で表示 |
| 入力済みチェック | `GuideProgress.checked`。コピーしただけでは付かない |
| 進捗保存 | `PUT /api/tax/returns/{year}/guide/progress`。本人のみ |
| 未入力項目の警告 | 第3部 3-2 と上部の進捗バー |
| A4 PDF | reportlab（既存 `pdf.py`）。項目・金額・チェック欄・公式リンク（QR なし）。「転記用。申告書ではありません」 |
| 国税庁へのリンク | 作成コーナー https://www.keisan.nta.go.jp/ 、e-Tax https://www.e-tax.nta.go.jp/ 、手引き（年度別 URL は設定データ）、青色申告承認申請、電帳法のページ |
| 文言 | 一般的な制度説明と NOXIA の集計値の提示にとどめる。個別の税務判断は「税理士・税務署へ」。税理士法 Q&A 問 2-1・6-3 に沿う |

## 6. 年度公開後の確定手順（運営者）

1. 作成コーナー令和8年分が公開されたら、テスト用の数字で決算書→申告書の全画面を操作し、各入力欄の **正式な項目名と順序** を記録する（スクリーンショットは個人情報を含めない）。
2. `TaxYearConfiguration(2026).guide` の `official_label`・`order`・`help` を更新し、`verified=true` にする。
3. 第3部の照合項目（計算結果の確認画面の表示名）も同様に確定する。
4. 変更は `TaxAuditLog(config_change)` に残し、`content_hash` が変わる。既に作られた版は影響を受けない（ガイドの表示だけが更新される）。
5. 令和9年分以後は同じ手順で新しい年度の設定を作る（コピーして差分を確認）。

## 7. 制約と注意

- 作成コーナーは他社の `.xtx`・`.data` を取り込めない。NOXIA の XTX は **e-Tax ソフト（WEB 版／ダウンロード版）で読み込む経路**専用（`tax_etax_export.md`）。ガイドでは混同しないよう明記する。
- 作成コーナーの令和8年分画面は未公開。公開前の表示は令和7年分の操作手引きに基づく **仮の項目名**（「要確認」）である。
- マイナンバー・氏名・住所などの基本情報は NOXIA に無い。利用者が作成コーナーで入力する。
- 医療費の明細・寄附金の明細・生命保険料の証明書の内訳は作成コーナー側で入力。NOXIA は合計の確認用の計算のみ。
- 青色 55／65 万円控除・消費税・不動産所得などは未対応（`unsupported_items`）。該当者にはガイドの先頭で「税理士に相談」を表示。
