# 経理・源泉所得税 運用マニュアル

NOXIA で、日々の売上・キャスト報酬・源泉所得税・現金出納・月次経理をまとめて管理し、経営者ご本人が e-Tax で納付するまでの手順です。
NOXIA は税務の判断・申告書の作成・e-Tax の送信を代行しません。判断に迷う点は税理士等にご相談ください（`TAX_OPEN_QUESTIONS.md`）。

---

## 0. 日払いの設定（店舗設定 → 営業ルール →「日払い（お渡し）」）

- **源泉所得税を差し引く**: 既定は **OFF**（差し引かない）。OFF の間は、お渡しのときに源泉所得税を計算せず報酬をそのまま渡します。「税務区分の確認待ち」の表示も出ず、源泉徴収の明細・月次集計にも入りません。ON/OFF の変更はオーナーだけ。ON にすると、その後のお渡しから下の 1〜4 の設定に従って差し引きます（OFF の間に渡した分はさかのぼって計算しません）。
- **お渡しのときに引く控除**: 備品代など、名目と割合（%）を登録します（10個まで）。その日の報酬（時給×勤務時間＋バック）に対する割合です。
  - お渡しの画面（「渡した」の確認・「金額を変えて渡す」）にチェック欄が出て、**チェックを入れたときだけ**引きます。「最初からチェック」にした項目はチェックが入った状態で出ます（外せます）。
  - 同じ日の分を2回に分けて渡すときは、1回目に引いた項目は2回目には引きません。「渡した」を取り消すと、また引けるようになります。
  - 契約の厚生費などの控除（下の 3）は、これまでどおりチェックなしで毎回引かれます。

## 1. 最初に一度だけ（オーナー）— 源泉所得税を差し引く場合

1. **事業者を登録**: メニュー「経理 → 経理設定（事業者・権限）」→「＋ 事業者を登録」。
   - 法人か個人事業主か、所在地、所轄税務署、**源泉所得税の整理番号**（給与支払事務所等の開設届出書を出した後に税務署から通知される番号）。
   - 給与等の納期の特例の承認を受けている場合は ON（給与だけ半年ごと。ホステス報酬は特例の対象外で毎月）。
2. **店舗の事業者を設定**: 同じ画面の「店舗の事業者」で各店舗を選ぶ。同じ事業者が複数店舗を運営していれば、源泉所得税はまとめて集計されます。
3. **キャストの契約を登録**: 「経理 → キャスト契約・税務区分」→「＋ 契約を登録」。契約区分、契約期間、**報酬計算期間**（日ごと・半月ごと・月ごとなど）、支払方法、厚生費などの控除、契約書。
   - 店長も登録できますが、税務区分の確定はオーナーだけです。
4. **税務区分を確定**: 各契約の「税務区分を確認」で、働き方の実態をチェックし、「ホステス等の報酬・料金」か「給与所得」を選び、判断の理由を書いて確定します。
   - 契約書の名称（業務委託など）だけでは決めないでください。雇用に近い実態のチェックが多いと警告が出ます。
   - 確定するまで、そのキャストの日払いは源泉所得税を引かずに「要確認」になります。
5. **記帳代行・税理士に頼む場合**: 経理設定の「記帳代行担当者・税理士等への権限」で、相手のユーザー名・役割・有効期限を入れて付与。いつでも停止できます。

## 2. 毎日（店長・スタッフ）— 営業中の操作はこれまでと同じ

1. 出勤・退勤はこれまでどおり。退勤するとお渡し額が出ます。備品代などを引くときは、その画面でチェックを入れてから「渡した」（金額がその場で変わります）。
2. （源泉所得税を差し引く設定の店舗）ホステス報酬と確定したキャストは、お渡し額が **源泉所得税を引いた額** になっています（カードに「源泉所得税（お店が預かる）−¥…」）。
   厚生費などの控除も別の行で引かれます。
3. 現金を手渡ししたら「渡した」。レジからは手渡し額だけが出金され、源泉所得税はお店の預り金として記録されます。
4. 「⚠ 税務区分の確認待ち」が出ている人は、源泉所得税を引かずに渡します（あとでオーナーが確認します）。
5. 間違えて「渡した」を押したら「取り消す」（記録は残り、源泉所得税の計算も取り消されます）。
6. 「日払い精算書（PDF）」で、その日の一覧とキャストごとの精算書を出せます（キャスト本人に渡す控え）。
7. いつもどおりレジ締め。源泉所得税はレジの現金に入っていないので、理論現金からは手渡し額だけが引かれます。

## 3. 毎月（オーナー）— 翌月10日までに納付

1. 「経理 → 源泉所得税管理」を開く。期限が近い月・期限超過・要確認は上に赤・黄色で出ます。
2. 対象の月を押して「**集計する**」。
3. 「要確認の支払い」があれば「確認して確定」。ホステス報酬として確定すると、支払時に引かなかった税額が「支払時に未徴収」として計上されます（その分も納付が必要です）。
4. 店舗別・キャスト別・転記用の数字を確認し、「**経営者確認**」（パスワードの再確認あり）。
5. 「転記用PDF」を見ながら、**ご本人が e-Tax** で「所得税徴収高計算書データ」を送信し、納付します（画面のリンクから e-Tax へ）。
   - 報酬・料金等: 区分「ホステス等の報酬・料金（08）」、人員、支払額、税額、摘要「支払額からの控除額」。
   - 年度は納付日の会計年度（4月〜翌3月）です。期限後に納付する場合は延滞税等の扱いを税務署の案内で確認してください。
6. 納付したら「**納付を記録する**」（納付日・金額・方法）。納付すべき税額と一致すれば「納付済み」になります。
7. 受信通知や領収証書は「月次損益・経費・証憑」の証憑に「納付証憑」として保存。
8. 給与（雇用）の人がいる場合は、給与計算ソフトで計算した源泉徴収額を「給与（給与計算ソフトの結果）」タブで入力し、同じように確認・納付・記録します（納期の特例なら7月10日・1月20日）。

確認した後に支払い・取消・訂正があると「**訂正あり**」になります。もう一度「集計する」→「経営者確認」をしてください。納付済みの月で税額が増えた場合は差額を納付して記録します。

## 4. 訂正のしかた
- 渡した記録の取り消し: 出勤・お渡し画面の「取り消す」（レジ締め前のみ）。締め後は営業日を再開して取り消す。
- 過払い・計算誤りの訂正: 源泉所得税管理の月の詳細 →「＋ 訂正を登録」（元の明細は変わらず、訂正を記録した日の月に増減）。
- 経費の誤り: 「取消・訂正」で取り消して正しい金額で登録し直す（元の記録は残る）。

## 5. 記帳（記帳代行担当者またはオーナー）
1. 「経理 → 月次損益・経費・証憑」。
2. 口座・カード・個人のお金で払った経費を「経費」に登録（領収書のファイルも一緒に）。レジ現金の経費は「開店・日締め・現金」で記録済みなので二重に登録しない。
3. 経営者が個人のお金を店に入れた・店のお金を個人に移したときは「経営者との資金移動」（売上・経費にしない）。
4. カード決済会社からの入金は「カード入金」。
5. 「最新の記録から仕訳を作る」→「照合」で、売上・現金差額・カード入金・源泉所得税と納付が一致しているか確認。
6. 「月次損益」で黒字・赤字を確認（仮勘定があれば内容を確認して確定させる）。

## 6. freee 連携
1. 運営者が freee のアプリ登録を行い、サーバーに `FREEE_CLIENT_ID` / `FREEE_CLIENT_SECRET` / `FREEE_REDIRECT_URI`（`https://<NOXIAのドメイン>/accounting/freee`）を設定し、`FREEE_LIVE_ENABLED=1` にする。
2. 「経理 → freee 連携」→「freee と接続」→ freee の画面で事業所を選んで許可。
3. 「freee の科目を読み込んで設定」で、すべての科目・税区分を freee 側に対応付けて保存（税区分は税理士等に確認）。
4. 「この日以降の仕訳を送る」で、freee に手入力済みの期間を除く。
5. 「未送信・変更分を freee に送る」。失敗は「再送」。**結果不明**は freee 側を確認してから「確認した」（あった場合は freee の振替伝票ID を入力）。
6. API が使えないときは「仕訳CSV」をダウンロードし、freee の「他社会計ソフト仕訳のインポート」で列を割り当てて取り込む。
- 練習は「模擬接続で試す」（freee には送りません）。

## 7. 運営者の作業
- **税制改正**: Django 管理画面の「源泉徴収ルール」で、現行ルールに適用終了日を入れ、新しいルール（適用開始日・税率・内訳・控除額・根拠・確認した資料）を追加。過去の明細は保存済みの版で残るため変わりません。
- **臨時の祝日**: 環境変数 `ACCOUNTING_EXTRA_HOLIDAYS=YYYY-MM-DD,...` を設定。
- **証憑ファイル**: `MEDIA_ROOT`（既定 `backend/media`）をバックアップ対象に含める（DB のバックアップ `scripts/backup-db.ps1` には含まれません）。保存期限内は削除しない。
- 本番 DB へのマイグレーション適用（`manage.py migrate`）はデプロイ手順で実施（`staff 0003`、`accounting 0001・0002`）。

## 8. 保存期間の目安（電子帳簿保存法・法人税法・所得税法）
- 帳簿・証憑: 法人は7年（欠損金の繰越がある事業年度は10年）、個人事業主は7年（書類により5年）。NOXIA の証憑は取引日から法人10年・個人7年を保存期限の目安として表示します。
- 電子取引のデータは、取引年月日・金額・取引先で検索できる状態で保存し、訂正・削除の履歴を残します（NOXIA の証憑は論理削除・ハッシュ値・登録者を記録）。
- 具体的な保存要件の満たし方（事務処理規程の作成など）は税理士等に確認してください。
